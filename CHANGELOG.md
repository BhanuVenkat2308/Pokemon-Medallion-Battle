# Changelog

## 1.0.0 — 2026-11-10

Initial release of Pokémon Medallion Battle — Solo Edition.

- 393 Pokémon entries, collection management, evolution and discovery tracking.
- Gym progression, practice battles, automatic powers and animated confrontations.
- Starter selection and two unique welcome packs.
- Regular packs, daily discovery packs and field tasks.
- 25 solo legendary raid expeditions with persistent progress and stage rewards.
- Responsive five-section interface with polished desktop and mobile layouts.
- Local saves with export/import and isolated regression tests.

This release is a solo fan recreation. Saves are local to each browser and origin.
