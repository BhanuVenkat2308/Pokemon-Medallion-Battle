# Pokémon type symbols

Official Pokémon TCG energy/type images, archived by Bulbagarden from Pokémon Korea (https://pokemonkorea.co.kr/).

Source file pages: https://bulbapedia.bulbagarden.net/wiki/File:Fire-attack.png and corresponding Grass, Water, Lightning, Fighting, Psychic, and Colorless files.
Downloaded from https://archives.bulbagarden.net/media/upload/ on 2026-10-28. Pokémon artwork belongs to its respective rights holders. Used in this unofficial fan recreation; no ownership is claimed.

Tier icons are original Medallion Battle images from Bulbagarden Archives: `Medallion_Battle_Tier_1.png`, `Medallion_Battle_Tier_2.png`, and `Medallion_Battle_Tier_3.png`. Used for the roster's tier-targeting powers.
